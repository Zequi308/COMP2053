Lenguajes del Desarrollo Web

HTML se encarga de estructurar el contenido de un sitio web, mientras que CSS define la presentación, el diseño visual y la estética.

  • HTML (HyperText Markup Language)
  • CSS (Cascading Style Sheets)
  • JavaScript
  • Python

Separar la estructura del diseño facilita el mantenimiento y la reutilización del código en múltiples páginas.
